# 隐私政策与免责声明统一入口设计

## 目标

让小程序内的隐私披露、数据注销路径和营养服务免责声明可读、可达，并与微信公众平台隐私保护指引使用同一套收集项和用途描述。

## 范围

1. 个人中心设置区保留一个卡片，名称为“隐私政策与免责声明”，替代原“隐私与数据”。
2. 卡片进入独立政策页；不再使用简短隐私弹窗，避免同一信息出现两份不一致的版本。
3. 政策页包含以下可审查内容：
   - 收集项：微信登录身份标识、用户主动设置的昵称头像、身体与营养目标档案、饮食记录、主动上传的识别图片、反馈内容。
   - 用途：账号识别与数据隔离、记录与目标展示、餐食营养估算、AI 识别及教练建议、问题反馈处理。
   - 存储与保留：数据通过 HTTPS 写入 CloudBase；产品账号存续期间保留，注销成功后删除产品资料、记录和私有图片。
   - 权利与路径：用户可在资料页修改信息、在当前设备退出登录、从页面进入“注销 Nordic Nutri AI 产品账号”。注销不影响微信账号。
   - 权限用途：相机/相册仅用于用户主动选择餐食图片或保存分享海报；昵称/头像仅在用户主动授权或编辑时使用。
   - 免责声明：营养识别、营养估算与教练建议仅供日常饮食参考，不构成医疗诊断、治疗或处方；健康问题应咨询专业人士。
4. 在首页与已有的识别、教练结果路径保留简短、可见的非医疗提示。首页仅增加低干扰的一行提示，不改变核心记录流程。

## 信息真实性约束

- 当前仓库未配置产品主体名称或联系邮箱，页面不伪造这些信息。
- 页面使用已存在的“我的 → 反馈与帮助”作为实际联系渠道。
- 上线前，产品负责人须把产品主体、联系邮箱、版本号、生效日期同时补入页面与微信公众平台隐私保护指引；发布检查清单继续对此做阻断检查。

## 交互与边界

- 政策页是只读说明页，显示返回按钮、分节内容和注销入口；不触发数据请求或权限申请。
- 点击注销入口跳转既有二次确认页；退出登录仍是独立操作。
- 不改动登录、CloudBase 会话、数据库权限、账号注销 API 或删除范围。

## 验收

- 个人中心只存在一个“隐私政策与免责声明”卡片，并能进入政策页。
- 政策页能够看到收集、用途、保留、AI 处理、用户权利、注销路径和免责声明。
- 识别/教练结果可见非医疗提示；首页存在同样含义的提示。
- 单元测试覆盖路由、入口文案、政策披露字段和免责声明。
- TypeScript、小程序构建与 WXSS 兼容性检查通过。
