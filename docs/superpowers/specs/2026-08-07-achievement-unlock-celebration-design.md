# 成就解锁庆祝弹窗

## 目标

让成就解锁更有仪式感，同时保持 Nordic Nutri AI 的自然、克制风格。

## 视觉与交互

- 页面保持可见，并覆以轻微半透明深色遮罩与 3px 模糊；不使用传统彩色礼花或顶部下落彩条。
- 成就卡片从底部轻弹入场：90% → 105% → 100%，同时由透明变为可见。
- 庆祝效果从屏幕左右边缘中部同时喷射，持续约 3.8–4.2 秒：每个粒子拥有独立的高度、速度、旋转、宽碰撞区坐标和散落终点。粒子先向对侧快速交错，之后在屏幕两侧与中部的不同横向位置分散，再自然下落；不得汇聚成屏幕中央竖线。仅使用米白碎片、浅绿色叶片、金色小光点和半透明圆点，营造完成健康目标后的掌声感。
- 移除“成长里程”及其进度条，弹窗仅展示解锁状态、成就名、条件与操作。
- “成就已解锁”使用更大的森林绿色字级，作为明确的庆祝标题。
- 主操作文案为“收下这份成就”，确认庆祝并关闭弹窗。
- 次操作文案为“查看全部成就”，确认庆祝后跳转至成就页。

## 验收

- 礼花覆盖整个屏幕，而非仅位于卡片内。
- 礼花可见时间明显长于原 720ms 动画。
- 首次观看可清楚辨认左右边缘同时发射，而非顶部或中央下落。
- 弹窗不再显示成长里程或成就总数。
- 新文案和标题层级在微信小程序构建中可用。
