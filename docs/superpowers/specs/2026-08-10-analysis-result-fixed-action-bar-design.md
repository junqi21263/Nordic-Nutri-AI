# 扫描结果页固定操作栏设计

## 目标

扫描结果出现后，底部的免责声明、`调整份量` 与 `保存本餐` 始终固定在屏幕底部，无需滚动到页面末尾才可操作。

现有扫描结果页的结构、文案、按钮样式、间距、交互和最终静态视觉均保持不变。仅调整底部操作区的定位方式及其 reveal 动画承载节点。

## 范围

- 新增一个固定底栏容器，包裹既有免责声明和两个既有操作按钮。
- 固定底栏位于屏幕底部、覆盖安全区，并使用已有浅色背景和细分隔线语言。
- 为分析结果的可滚动内容预留等于底栏高度的底部空间，确保 NOVA 洞察等最后内容能够完整滚动到固定栏上方。
- 现有 reveal 时间线不变：到达 `bottomActionReveal` 时，整条固定底栏从下方 24px 淡入上移；完成后保持固定可见。
- 降低动态效果偏好下，底栏直接可见。

## 不做

- 不修改扫描结果页的卡片、数据、文案、按钮造型或保存/调整份量的交互。
- 不增加底部弹窗、不新增 API、不改动分析数据与保存链路。
- 不改动其他页面的固定操作区。

## 实现边界

### 页面

`mini-program/src/pages/analysis-result/index.tsx`：将免责声明和既有操作区置入 `analysis-result-page__bottom-bar`。动画数据属性从子节点移动到该容器，保证两项内容作为一个固定区域同时 reveal。

### 样式

`mini-program/src/styles/page.scss`：

- 固定底栏：`position: fixed; left: 0; right: 0; bottom: 0; z-index: 20`。
- 保留页面横向边距、安全区和两按钮网格；把操作区原有的底部安全区内边距移至父容器，避免重复空白。
- 为固定栏增加与现有餐食详情固定操作区一致的浅色背景与顶部弱分隔线。
- reveal 只作用于固定栏容器，使用既有 340ms `cubic-bezier(.22, 1, .36, 1)`，即录屏中的柔和 bottom slide-up，而非重新设计动画。

`mini-program/src/styles/layout.scss`：为 `page-layout--analysis-result` 增加固定底栏高度预留，避免滚动末尾被遮挡。

## 验收

1. 结果页首屏始终可见免责声明、调整份量和保存本餐。
2. 页面向下滚动时，操作栏位置不移动；NOVA 洞察可完整查看且不会被底栏遮住。
3. 首次扫描结果 reveal 时，底栏在最后阶段从下方淡入上移，随后固定。
4. 重播 reveal 和减少动态效果均保持可用。
5. 保存本餐与调整份量原有点击行为不变。
