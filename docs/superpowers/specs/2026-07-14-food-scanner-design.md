# Food Scanner Design

## Purpose

将「扫描」页从占位取景器升级为与首页一致的营养拍摄入口。用户可切换闪光和本地图册模式，启动拍摄后明确看到本地图片被扫描，再进入既有分析结果流程。

## Aesthetic direction

Organic/natural：暖白页面承托深森林绿取景框；使用既有 PingFang SC 品牌字体和 `#163422`、`#0c1f14`、`#b5ccba`、`#f2ebe1` 色板。此为项目既有品牌 token 的窄范围沿用。

## Layout

- 顶部使用专用扫描页头：在运行时安全区下方显示返回、食物扫描、标题、说明和关闭按钮；不侵入灵动岛或胶囊区域。
- 取景器保留四角定位框。普通态用餐盘图标提示构图；图库态显示本地餐食缩略预览。
- 控制区包含闪光、模式、定时、图库和圆形快门，均为本地 Lucide SVG。
- 点击快门或图库候选后进入扫描态：预览上出现从上向下循环的绿色扫描线与“正在识别餐品与营养信息”，约 900ms 后沿用现有随机本地分析结果页跳转。
- 底部继续使用统一 custom tab bar，扫描项为选中态。

## Interaction and error boundary

- 不调用真实相机、相册或云端服务；保持现有 `ScannerStore` 的闪光、图库、候选餐品和随机本地分析行为。
- 扫描过程中禁止重复触发捕获；若页面卸载，延时跳转会清理。
- 用户可在扫描前切换闪光/图库模式；扫描后才锁定控制区。

## Validation

- 单测覆盖扫描页只使用 `NordicIcon`，扫描状态和动画 class 的存在，以及原始分析跳转路径。
- 运行 unit、typecheck、build:weapp 和 WXSS 校验。
