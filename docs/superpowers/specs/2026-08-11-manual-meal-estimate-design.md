# 手动记录：时间与营养估算设计

## 目标

让用户在手动记录页填写餐食名称后自动获得可编辑的营养估算，并可修改记录日期与时间。

## 交互

- 字段名使用“餐食名称”和“记录时间”。
- 记录时间由日期与时间选择器组成，初始值为当前本地日期时间。
- 用户完成餐食名称输入后，等待 600ms 调用现有 `/meal-analysis` 接口，以 100g 为基准填充四项营养值。
- 手动改过任何营养字段后，后续自动估算不会覆盖该字段；“重新估算”可明确覆盖四项值。
- 从食物库带入餐食时，保留现有按份量计算逻辑，并且可继续手动修改。

## 保存与回退

- 保存请求采用用户选择的记录日期和时间。
- 自动估算失败时保留用户输入并显示可手动填写的提示，不阻断保存。
- 本次不改餐食表、鉴权或函数访问规则。

## 验证

- 单元测试覆盖保存原始识别份量、标题估算、手动值不被覆盖、记录时间写入。
- 执行云函数测试、lint、typecheck 和 weapp build。
