# 扫描结果固定底栏入场动画设计

## 目标

扫描结果页面的免责声明与操作按钮保持固定在底部，但不在页面初始阶段露出。待主信息、营养评分与下方内容完成 reveal 后，固定栏整体从屏幕底部滑入。

## 约束

- 不改变固定栏的尺寸、背景、按钮、文案、交互或滚动空间预留。
- 不改变其他 reveal 阶段、数据逻辑或页面最终静态状态。
- 仅修改现有 `bottomActionReveal` 的可见起点、持续时间与完成时间。

## 动画

- 初始：`opacity: 0; transform: translateY(100%)`，固定栏完全位于屏幕外。
- 触发：保持在现有 `bottomActionRevealAtMs = 2200ms`，确保前序内容已完成展示。
- 入场：`opacity: 1; transform: translateY(0)`，420ms，沿用 `cubic-bezier(.22, 1, .36, 1)`。
- 完成：总 reveal 完成点推迟到 2700ms，以覆盖 420ms 入场结束时间，避免移除动画选择器造成视觉跳变。
- 降低动态效果偏好下直接显示。

## 验收

1. 扫描结果进入时，底部固定栏在前 2200ms 完全不可见。
2. 2200ms 后，免责声明和两个按钮作为一个整体由页面底部滑入。
3. 动画结束后该区域保持固定，滚动内容不会遮挡或覆盖它。
4. 页面完成动画后，最终视觉与固定栏修复前一致。
