# First-run tips (lightweight coach marks)

Date: 2026-08-05

## Goal

Guide first-time users through the first meal loop without a dedicated tutorial page.

## Form

Reusable dismissible tip bar (copy + CTA /「稍后」), shown once per tip id via local storage `nordic-nutri:first-run-tips:v1`.

## Placements

1. Home — empty / first visit: tip to photograph the first meal (`1/3`)
2. Food scanner — tip on framing / lighting before first capture (`2/3`)
3. Meal records — tip to review today's meals / continue the loop (`3/3`)

## Out of scope

Full-screen walkthrough, multi-step overlays, analysis-result tip (step 3 moved to records).
