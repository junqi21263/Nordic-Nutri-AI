# Android DEV 记录提醒页面 Stitch 重构设计

## 背景

本次仅覆盖 Android DEV APK 的记录提醒页面。视觉基准为用户提供的 Stitch 导出源文件：

- `/Users/lewis/Downloads/stitch_nordic_nutri_v2_ux/DESIGN.md`
- `/Users/lewis/Downloads/stitch_nordic_nutri_v2_ux/code.html`
- `/Users/lewis/Downloads/stitch_nordic_nutri_v2_ux/screen.png`

Stitch 文件是静态 HTML/CSS 原型，不能直接替换 Taro 页面；实现需要将其视觉规则转译到现有 Android H5/Taro 组件，并继续复用现有提醒业务逻辑。

## 目标

让用户可以在一个安静、易理解的页面中开启或关闭记录提醒，并快速调整早餐、午餐和晚餐时间。页面需要表达“轻轻提醒，记录后当天自动跳过”，避免打卡压力。

## 不变范围

- 只修改 Android DEV APK。
- 不修改提醒判断规则、Push 接口、CloudBase 云函数或数据库。
- 继续使用现有 `smartReminderStorage`、`refreshAndroidSmartReminders`、通知权限请求和云端同步。
- 保留失败提示、时间范围校验和返回行为。
- 不新增第三方 UI 组件或字体网络请求。

## 视觉方向

采用 Stitch 的 Organic/natural + Nordic editorial journal 方向：米白纸张感背景、深森林绿操作色、低对比鼠尾草区域、暖燕麦时间入口，以及轻量的层叠和细分隔线。

### 颜色

- 背景：`#F9FAF7`
- 卡片：`#FFFFFF`
- 主森林绿：`#1C3F32`
- 主要文字：`#191C1B`
- 辅助文字：`#556159`
- 鼠尾草底色：`#E8EFEA`
- 时间入口：`#F3ECE1`
- 成功反馈：`#2D7049`
- 错误：`#BA1A1A`

### 字体

- 标题和餐次标题使用 Newsreader 风格；中文沿用项目已有中文回退栈。
- 正文、时间和按钮使用 Manrope 风格；中文沿用项目已有中文回退栈。
- 不加载远程字体，保证 APK 离线稳定。

## 页面结构

1. 保留现有页面导航、返回按钮、页面标题和副标题。
2. 顶部放置浅绿色“记录提醒”说明卡：铃铛图标、总开关、简短说明和“记录后当天自动跳过”提示。
3. 将早餐、午餐、晚餐合并为一个统一排程面板，而不是三个纵向大卡片。
   - 每行左侧为独立餐次 SVG 图标、餐次名称和允许时间标签。
   - 右侧为小尺寸开关。
   - 下方为“提醒于 HH:mm · 修改”时间入口。
   - 行之间使用低对比细分隔线。
4. 底部放置左对齐的说明行：每天每个餐次最多提醒一次，记录后当天自动跳过。

## 交互与动效

### 页面进入

标题、说明卡、排程面板和底部说明依次淡入并上移约 8px；尊重 `prefers-reduced-motion`，减少动效时不做位移动画。

### 开关

- 轨道使用 44x24 左右的小尺寸，不再使用当前偏大的开关。
- 滑块以短促的弹性移动完成状态切换，轨道颜色同步过渡。
- 成功开启或关闭后显示页面中心的反馈弹窗，包含状态图标、餐次名称和当前时间/状态。
- 弹窗使用背景遮罩、轻微缩放进入和淡出，默认约 1.8 秒后关闭，可点击关闭。
- 权限拒绝或云端同步失败使用同一套弹窗/反馈视觉，但保留错误语义。

### 时间编辑

- 点击“修改”打开自定义底部时间面板，不使用系统日期/时间组件。
- 面板沿用 Stitch 的圆角、拖拽条、深森林绿确认按钮和自定义上下拨动小时/分钟滚轮。
- 仅展示当前餐次允许范围内的小时和 5 分钟刻度。
- 取消丢弃草稿；确认后保存、同步本地提醒并显示“时间已更新”。

## 数据流

```text
页面加载
  -> smartReminderStorage.load(userId)
  -> 渲染总开关、三餐状态和时间

用户切换开关/确认时间
  -> 构造下一份 SmartReminderSettings
  -> 本地保存
  -> 继续调用现有 Android 提醒刷新与必要的云端设置同步
  -> 展示统一反馈弹窗
```

## 验收标准

- Android DEV APK 页面布局与 Stitch 源文件的层级和视觉语言一致。
- 页面不再使用三个过大的餐次卡片堆叠；三餐在统一排程面板内对齐。
- 每个入口使用独立、统一线性风格的 SVG 图标。
- 总开关和餐次开关可用，开启/关闭均有动画反馈。
- 时间编辑支持上下拨动小时/分钟，取消和确认行为正确。
- 重新打开页面后保留上次状态和时间。
- 权限拒绝、云端失败、非法时间仍有清晰反馈。
- 现有提醒逻辑和 Push/CloudBase 接口行为不变。
- 完成构建、安装后，在真机上验证页面进入、开关、弹窗、时间编辑和重新打开状态。

## 2026-09-15 反馈弹窗修订

- Android 页面头部移除右侧仿小程序胶囊控件，标题继续保持页面视觉中心。
- “记录完成后”说明行使用固定图标容器和一致行高，让图标与正文在视觉中线对齐。
- 关闭状态正文和弹窗主说明均保持单行；窄屏不得通过缩小主体字号破坏层级。
- 开启反馈继续使用现有闹钟晃动与向外扩散动画。
- 关闭反馈使用独立 `ReminderPausedModal`，不得复用开启动画组件或动画类：静音铃铛轻微下沉、斜杠绘制、外圈向内收拢后静止。
- 关闭反馈文案为“已关闭就餐提醒”“之后可以随时重新开启”“需要时，我们仍在这里。”，按钮为“知道了”。
