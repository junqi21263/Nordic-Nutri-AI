# 登录入口底部弹层设计

**状态：用户已选择 A，待实施**

## 目标

将退出登录或启动认证失败后的整页登录入口，调整为与现有小程序一致的底部半屏弹层；不改变认证协议、Session 持久化或现有 Tab 页面。

## 交互

1. 冷启动先执行既有 Session 恢复与一次静默微信登录。
2. 用户主动退出或认证失败后，应用停留在安全的登录入口页面，并自动打开不可跳过的 BottomSheet。
3. 弹层包含品牌标识、简短说明与唯一主按钮“微信登录”。不显示 token、code、openid、请求 ID 或原始错误。
4. 登录请求期间按钮 loading 且不可重复点击；失败仅显示“登录未完成，请稍后重试”，用户可再次点击。
5. 登录成功后关闭弹层并按既有 onboarding 状态进入引导或首页。

## 视觉与范围

- 复用现有 `BottomSheet`、`AppCard`、`AppButton`、颜色和圆角；不新增 Tab、不重做启动页。
- 使用既有底部弹层进入/退出动画和遮罩；不提供“暂不登录”或关闭按钮，避免未认证用户进入受保护业务路径。
- Phase 3A-2 餐次 CRUD 的数据、RLS 与页面联调不受该样式调整影响。

## 验收

- 退出登录后只出现一次底部登录弹层，不自动再次发起 `wx.login`。
- 冷启动有有效 Session 时不显示弹层。
- 点击登录期间不能重复提交；成功进入业务路径；失败保留弹层并可重试。
- 现有 Vitest、TypeScript 与微信构建通过。
