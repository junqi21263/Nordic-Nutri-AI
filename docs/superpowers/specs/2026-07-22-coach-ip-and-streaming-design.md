# NOVA 教练 IP 与流式回复设计

## 目标

在不改变 Nordic Nutri 现有教练页页面结构、底部导航和饮食建议边界的前提下：

1. 增加原创人物化教练 IP「NOVA」；
2. 让 DeepSeek 的受约束用户可读回复以真实的 HTTP 分块方式逐段显示；
3. 保留现有 JSON 回复接口作为兼容与故障回退；
4. 仅保存校验完成后的完整回答，避免将不完整内容写入数据库。

## 视觉设计

NOVA 是轻量 2D 营养教练：圆形头像、自然卷短发、深绿色针织上衣、温和专业的表情。视觉仅使用本地 SVG，不请求外部图片服务。

- Header 保留“你的营养教练”和当日营养目标；下方新增问候 Hero，包含 NOVA、当前蛋白目标和两项快捷入口；
- 欢迎消息与教练消息左侧使用 NOVA 头像，替代通用机器人图标；
- 对话后依次呈现 AI 建议食物卡、今日进度卡与快捷回复；流式生成时显示头像、`NOVA 正在整理建议…` 和三点动画；
- 回答逐段抵达后，复用既有白色教练气泡；输入区继续固定在 TabBar 上方，不与进度卡重叠；
- 不新增浮层或固定区域，不改变评分条、输入框和 TabBar 的已修复位置。

## 接口与数据流

新增 `POST /coach-answer/stream`，其输入与既有 `POST /coach-answer` 相同：

```json
{ "clientRequestId": "uuid", "prompt": "晚餐怎么补蛋白？", "date": "2026-07-22" }
```

服务器流程：

1. 校验产品 session、请求大小、日期和幂等键；
2. 先执行既有医疗风险与非营养问题边界；这两类规则答案直接返回单个完成事件，不调用模型；
3. 对合规营养问题，构建既有最小可信上下文并调用专用的 DeepSeek 流式文本提示词；该提示词只生成不超过 500 字的日常营养建议文本，不输出 JSON 或 Markdown 代码块；
4. 将上游文本增量转换为换行分隔 JSON（NDJSON）事件：`delta`、`complete`、`error`；
5. 仅当完整文本通过长度和安全词校验后，保存用户消息、助手消息；`answer` 继续保存由可信上下文生成的结构化摘要，兼容既有数据契约；
6. 若流式链路不可用、上游中断或输出未通过校验，返回既有 `rule_v2` 完整安全回答并保存。

事件格式：

```json
{ "type": "delta", "text": "晚餐可以先补充" }
{ "type": "complete", "message": { "id": "uuid", "role": "assistant", "content": "..." }, "reply": { "source": "deepseek" } }
```

小程序优先使用支持分块回调的请求通道读取 NDJSON：先插入一个本地的 `streaming` 教练气泡，再按 `delta` 追加文本；收到 `complete` 后以持久化消息替换该临时气泡。若当前基础库不支持分块回调，或请求失败且未接收到任何分块，则退回既有 `POST /coach-answer`。

## 边界与安全

- 只有认证后的产品用户可访问两条教练写接口；客户端不得传入用户 ID。
- DeepSeek API Key、系统提示词和可信营养上下文只在云函数内。
- 规则拦截仍优先于模型：医疗风险给出就医/专业咨询提醒；非营养问题仅说明教练范围并引导回营养、饮食、食谱或训练恢复。
- 流中不持久化、不展示模型原始 JSON；服务端只转发经过边界提示词约束的文本增量，完成后重新检查长度与安全词再持久化最终内容。
- 流式请求允许最多一个活跃回复；同一 `clientRequestId` 返回既有持久化结果，不重复调用模型。

## 验收与回归

- Node 测试覆盖：鉴权、非营养与医疗拦截不会调用模型、NDJSON 事件顺序、完整回答才持久化、上游失败回退、幂等。
- 前端测试覆盖：NOVA 头像渲染、思考中状态、增量追加、完成替换和普通接口回退。
- 运行：云函数 Node 全量测试；小程序单测、类型检查、Lint、格式检查、WeChat 构建和 WXSS 检查。
- 手动验收：微信开发者工具重新编译后，发送“晚餐怎么补蛋白？”应先出现 NOVA 思考状态，再逐段显示；发送“帮我写首诗”不触发模型并显示范围提示。

## 非目标

- 不引入 WebSocket、Cloud Run 或新的长期连接服务。
- 不改变现有数据库表结构；继续使用 `coach_messages.answer` 保存由可信上下文生成的结构化摘要。
- 不设计医疗诊断、处方、疾病干预或通用闲聊能力。
