# 保存庆祝动画与再次编辑设计

## 目标

以用户提供的 Stitch 录屏为基准，修复保存后庆祝弹窗的动画时序、垂直位置，以及再次编辑时未回填上次份量比例的问题。

## 动画与布局

- 弹窗保留背景模糊与卡片入场。
- 卡片初始为空状态；成功圆环从顶部连续扫过一圈，再绘制勾选，之后按顺序显示标题、营养标签、进度和操作按钮。
- 圆环使用普通视图的双半圆遮罩实现，不使用原生 Canvas，避免 Canvas 参与文档流造成图标与标题之间的额外高度。
- 弹窗在现有居中位置基础上下移 32rpx；卡片自身尺寸与文案不改变。

## 份量再次编辑

- 餐食项保留后端返回的 `aiQuantityG`（原始识别份量）。
- 从餐食详情进入“继续编辑”时，以每项 `confirmedQuantityG / aiQuantityG` 得出已保存比例；所有有效项一致时直接回填该比例。
- 缺少原始识别份量的手动记录或旧数据，安全回退为 100%。
- 保存调整继续只更新确认份量，后端的原始识别份量不被覆盖，因此重复编辑能稳定回填。

## 验证

- 动画组件测试：连续扫圈层、阶段延迟、无 Canvas 渲染层、下移偏移。
- 份量草稿测试：识别餐食按已保存比例回填；手动/旧记录回退 100%。
- 类型检查、WXSS 兼容检查和微信小程序构建。
