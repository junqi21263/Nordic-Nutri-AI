# P0 / P1 本地交互与页面补全

> 范围：仅小程序前端和本地存储；保留当前暖白、深绿、米色卡片及底部弹层语言，不接入云端或账号体系。

## 目标

完成可实际使用的本地记录闭环：重新打开后回到首页并保留资料/餐次；扫描提供相机/图库入口与失败回退；可手动记录；记录页可搜索筛选；首页、教练和个人资料页的操作都有明确去向。

## 实施顺序

1. 先为本地恢复、扫描选择、记录筛选、手动记录及教练加餐补充失败测试。
2. 增加轻量本地存储和首次完成标记；把资料、餐次和引导完成状态写入当前设备。
3. 完成扫描的相机/图库入口、失败回退弹层及手动记录页，并接入路由。
4. 为记录页接入搜索、筛选底部弹层与无结果恢复操作。
5. 补齐首页“全部记录”、教练加餐写入、空记录引导与目标调整入口，并统一页面标题/底部操作视觉。
6. 运行单测、类型检查、Lint、微信构建和产物校验。

## 验收标准

- 完成引导后再次启动默认进入首页；个人资料与新增/编辑/删除餐次在当前设备可恢复。
- 相机和图库入口调用原生媒体选择；取消/不可用时可使用示例餐盘或手动记录继续流程。
- 手动记录会校验数值并写入当天记录；记录页能按关键字、餐次或收藏筛选并清除筛选。
- 首页“全部记录”、教练“加入加餐”、编辑资料中的“调整目标”都可执行且反馈可见。
- 页面视觉不引入新色彩体系，底部弹层使用现有关闭/收起动效。
