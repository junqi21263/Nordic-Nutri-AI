# Remove Supabase Onboarding Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the live Supabase onboarding write path and persist the nutrition-plan completion flow through the existing authenticated CloudBase HTTP function.

**Architecture:** The mini program sends one Bearer-authenticated onboarding payload to `get-login-ticket/onboarding`. The function validates it, uses the session subject as the only user identity, versions body/goal records, updates preferences and profile completion, then creates an active nutrition plan. No page layout or navigation changes.

**Tech Stack:** Taro/React, CloudBase HTTP Function, CloudBase JS SDK RDB, PostgreSQL, Node test runner, Vitest.
