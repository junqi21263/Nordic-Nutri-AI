## 通用差异

- 颜色当前使用接近但未完整对齐 Stitch 语义色；特别是 `primary` 与 `primary-container` 未明确区分。
- 字体层级和字重在组件间重复定义，部分标题使用 700/750/800。
- 卡片、按钮、阴影和间距存在基础样式与后置覆盖两层定义。
- PageLayout、Onboarding 和 TopNavigation 还未共享同一套胶囊/安全区实现。
- 当前小程序无 `ScrollView` 页面内 padding 依赖，但需要持续保持 WXSS 降级约束。
