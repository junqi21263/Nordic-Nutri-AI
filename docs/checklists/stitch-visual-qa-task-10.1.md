## 微信 WXSS 复查清单

- [ ] `app.wxss` 及各页面 WXSS 无 `@layer`、`@apply`、`@property`、`:root`、CSS nesting、`backdrop-filter` 或不可见字符。
- [ ] `PageLayout` 不再生成全页 `ScrollView`，不再出现 `<scroll-view>` padding 的 WebView 警告。
- [ ] 圆形进度在不支持 `conic-gradient` 的基础库中通过既有 `ProgressFallback` 保持数值和线性进度。
- [ ] 不直接编辑 `mini-program/dist/weapp/`；所有产物均由 `src/` 重建。
