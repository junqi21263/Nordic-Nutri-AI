# 微信小程序发布检查清单

## 提交审核前

- [ ] 隐私政策已填写产品主体名称、有效联系邮箱、生效日期和版本号。
- [ ] 隐私政策说明昵称/头像、身体档案、饮食记录、私有图片、AI 处理、保存期限、用户权利和注销产品账号路径。
- [ ] 微信公众平台的隐私保护指引已逐项声明相机、相册、头像能力及用途，并与小程序页面文案一致。
- [ ] 已准备审核测试微信号、测试昵称、可识别的餐食图片和完整测试路径。
- [ ] 生产请求域名和下载/上传域名已配置为 HTTPS；开发者工具的 `urlCheck: false` 未作为审核依据。
- [ ] 已确认免责声明：营养识别与建议不构成医疗诊断或治疗建议。

## CloudBase 上线前

- [ ] 已记录目标完整 EnvId、当前套餐/到期状态和升级审批人。
- [ ] PostgreSQL、私有存储、`get-login-ticket` HTTP 函数和身份认证均属于同一目标环境。
- [ ] 已计划并审查待应用的 PG migration；未执行未经确认的迁移。
- [ ] 已确认函数的会话、AI、存储配置均为服务端变量，未出现在构建产物、日志或错误响应中。
- [ ] CLS 查询已验证只记录脱敏事件字段；没有请求体、图片 base64、OpenID、昵称或授权令牌。
- [ ] 告警接收人已配置：5xx、视觉识别失败率、视觉 p95、限流拒绝、注销失败和日成本 80%。
- [ ] 已记录回滚版本、函数版本和负责人。

## 真机验收

- [ ] 首次相机授权、拒绝后系统设置引导和相册备选路径均通过。
- [ ] 大图压缩与最终大小拒绝通过；弱网/离线后扫描草稿可恢复。
- [ ] 识别超时不会生成虚假餐食；用户可重试、编辑或改为手动记录。
- [ ] 连续点击保存和超时重试只生成一条餐食。
- [ ] “退出登录”仅清除当前设备会话。
- [ ] “注销 Nordic Nutri AI 产品账号”明确不影响微信账号，经二次确认后删除产品资料、记录和私有图片。
- [ ] 管理员只读核验：测试用户取消后，PG 用户级数据和私有对象均不存在。
